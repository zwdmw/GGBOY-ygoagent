# 对战与推理

## 命令行推理与会话

```bash
ygo-sky infer --model base-463m --device cpu \
  --observation resources/example-observation.npz --legal-count 2
```

输入形状定义在 `src/ygo_sky/observation.py`，各张量为 uint8。
推理严格加载 manifest 指定 checkpoint，不允许临时补参数。合法动作数必须在 1–128 范围；模型选中 padding 时拒绝执行。
Python 接口 `Predictor.choose(observation, count, session)` 按 session 保存 LSTM，`reset(session)` 删除状态。
示例观测用于接口验收，不代表一场完整对局。

## HTTP

```bash
python examples/http_infer.py --url http://127.0.0.1:8765 \
  --observation resources/example-observation.npz --legal-count 2 --session demo
```

`GET /health` 查询模型身份，`POST /infer` 推理，`POST /reset` 清理会话。
示例从 `YGO_API_TOKEN` 读取令牌；密码和令牌不写入配置或日志。
一场对局对应一个 session，下一场重新建 session 或 reset。不要将双方玩家共用同一 session。

## 233 服务器

默认配置是 `configs/duel/233.json`，地址 `s1.ygo233.com:233`，协议版本 `0x1362`。

```bash
export YGO_ROOM='private-room'
ygo-sky duel --config configs/duel/233.json --device gpu --output runs/233
```

233 官方说明：任意文字可作为房名；双方填写相同房名加入私房。
冻结训练卡组受当前禁限表限制，默认改用 `sky-striker-233.ydk`，40 主卡/14 额外。
对训练卡组的改动包括削减受限卡、去掉水晶机巧继承玻纤并补齐主卡。
这套变体仅验证接入，不作为原模型评估卡组或强度推荐。
若双方明确希望使用冻结卡组，可按官方房名代码在私房前加 `NF#`：

```bash
export YGO_ROOM='NF#private-room'
ygo-sky duel --deck resources/decks/sky-striker.ydk --device gpu --output runs/233-frozen
```

禁限表和房名规则可能更新，参考 <https://ygo233.com/usage>。
独立私房双客户端测试：

```bash
export YGO_ROOM='private-room'
python scripts/paired_233.py --output runs/233-pair
```

测试双方使用不同握手随机种子、共用只读模型权重并保存各自 LSTM 状态。

## 任意服务器与端口

```bash
ygo-sky duel --config configs/duel/233.json --host example.org --port 7911 \
  --version 0x1362 --nickname Sky463M --model base-463m \
  --deck resources/decks/sky-striker-233.ydk --device gpu --output runs/custom
```

对接目标需使用兼容的 YGOPro TCP 协议、选项消息和卡片编号。
卡片库与脚本更新后，既有训练语义覆盖范围不会自动扩大。

输出目录包含 `session.json`、`status.json`、`decisions.jsonl`、`network.jsonl` 和 `result.json`。
服务器返回录像时保存原始 `server-*.yrp` 及 SHA256。未收到录像、协议失败或不完整对局会在结果中明确记录。
房间口令、聊天认证信息从网络日志中脱敏；自行接入其他服务器时继续通过环境变量传递。
