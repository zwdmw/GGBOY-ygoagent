模型在网络对战时使用 `StructuredEncoder`，观测标签为
`structured-observable-v4-phase-history`。它无法直接获取全部原生 engine 查询，
网络输入与原生训练输入的差异必须说明，不能只因 tensor shape 一致就认定语义一致。

原有专项对照使用相同牌序、独立 LSTM、float32 GPU argmax，并经 8 局 3466 决策的
固定动作重放检查。证据只覆盖抽样轨迹。首次独立 GPU 编译控制曾出现分歧，
因此不宣称 GPU policy 普遍逐字节确定。

`resources/runtime/` 是 Linux CPython 3.11 原平台参考二进制。重编译产物的文件 hash
通常会变化，正式 loader 应同时保存参考二进制身份、源码构建身份及行为契约，
在完成构建与输入回归验证后绑定新 runtime。本次缓存重建与 330 次决策采样回归已通过，默认仍用参考产物。
历史 TCP 桥的公共事件 tensor 回归失败，详见验收报告；没有绕过 parity 门槛。

基线初始化谱系包含 `259000320` 权重。继续训练的配方注明 optimizer 未恢复，
这与精确恢复优化器状态不同。完整上游预训练与全部中间状态的复现应另行记录；
没有归档的部分不能宣称已经可复现。

发行副本的 checkpoint sidecar 将 `initial_checkpoint` 内部绝对路径替换为文件名。
源文件 SHA256、脱敏副本 SHA256 与修改字段列在 `release-info/resource-files.json`，相应模型 manifest 绑定副本 hash。
checkpoint 文件本身不变。历史池包含 11 个归档 checkpoint，两个采样池分别按 `configs/train/pools/` 精确选择 7/2 个成员。
