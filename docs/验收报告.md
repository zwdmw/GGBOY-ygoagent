## 233 对局

两客户端使用独立随机种子，避免同步猜拳持续平局。服务器正常收牌并开始对局。
第 13 回合结束，座位 0 获胜，LP 为 9000/0。座位 0/1 分别作出 251/136 次模型决策。
两个客户端记录的是同一场对局的两份视角，不能算作两场样本。对局运行约 46 秒，不含模型预热。

服务器返回的 `server-001.yrp` 为 YRP2 容器，650 字节，双方文件相同：
`768283550f1187f2db2ee693a4ed973bc96bc74d2436fde8a62fdf1e1dd9e5c9`。

默认兼容卡组 `sky-striker-233.ydk` 含主卡 40 / 额外 14，SHA256：
`a41627d622fc21d66cc3f391359b6d9f01c451b46de6b534ecaa61914e830165`。
冻结训练卡组在默认房间遭禁限检查拒绝，所以另外保存接入变体。
兼容变体的竞技强度没有评估。官方文档支持 `NF#房间名` 关闭禁限卡表，该配置与冻结卡组组合尚未实测。

## 输入与构建边界

参考训练引擎 SHA256：`65628475e6373f506fb59abc02627ab88ab8e5ee85ba959cc3503279eba4aee5`。
重建训练引擎 SHA256：`ebec40a09bf9213fd97b47268072bb3ce016e4d13f1c522357389809a2dd9dc4`。
采样回归种子为 2026100803，330 次决策共同轨迹 SHA256：
`6350c3c5d9e99e77308959220de8dcbb149d689a24f003cf2ad32be202a97d23`。
该检查覆盖一条抽样轨迹；默认 runtime 继续绑定参考产物。完整联网依赖构建路径尚未验收。

历史桥源码改变了公共事件与信息披露记录，无法仅凭编译成功宣称与训练输入等价。
严格回归门槛保留，网络输入对原生输入的隔离对照尚未通过。233 实战成功只证明网络对局能完成。

语义表重生成使用 alias-chain-v1。`cdb_exact` 为 14950×78，`lua_effects` 为 14950×16×64，`lua_mask` 为 14950×16，三者均与冻结表相同。
脚本缺失与别名回退分别为 1018 / 408；元数据与 NPZ 压缩字节不要求相同。

官方卡号表不能覆盖卡号 25955749、50588353、67441435、97616504。
两局累计未映射有效元素：cards 1014、actions 16、history actions 114。结果保留未知映射计数，不能解释为完整卡片覆盖的强度比较。

## 复现与发布范围

这是工程功能验收。32 step 短训练、小样本胜负、HTTP 同动作结果和单轨迹回归不能证明训练收敛、泛化、整体强度或任意轨迹的输入等价。
训练恢复权重而未恢复 optimizer；259M 之前的完整谱系未归档，历史独立验证/测试划分也不完整，冻结评估卡组存在于训练池。

源码与资源分包，发行副本的 sidecar 只将内部初始化路径改为资源名，并重新绑定 sidecar hash；模型、卡片数据、冻结语义表和参考引擎字节保持对应身份。
原 sidecar hash 与发行副本 hash 均记录在发布清单中。
新增原创整合代码与文档采用 MIT；上游许可分别保留，网络组件、模型与卡片资源的再分发条件仍有未明确项，公开下载不表示这些内容获得统一 MIT 授权。

独立解包安装的最终结果与包 SHA256 见 `release/manifest.json` 和 `release/acceptance.json`。
