## Linux 安装

当前已验收 Linux x86_64、Python 3.11。Windows 可用于整理文件，原生训练引擎的参考二进制只能在 Linux CPython 3.11 使用。

```bash
git clone https://github.com/zwdmw/GGBOY-ygoagent.git
cd GGBOY-ygoagent
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install -e .
export YGO_SKY_HOME="$PWD"
python scripts/download_resources.py --install
ygo-sky verify --model base-463m
ygo-sky verify --model specialist-464m
python -m pip check
```

资源包的固定 SHA256 见 [下载清单](../configs/resources.json)，也可与 Release 的 `manifest.json` 对照。准备脚本先校验大小和 hash，再在临时目录解包并写入空的 `resources/`；已有有效基线资源时验证并复用，已有资源损坏时保留现场。离线安装可用 `python scripts/download_resources.py --archive /path/to/sky-striker-resources.tar.gz --install`。
仅用推理服务不需要原生引擎。训练/原生验证需要：

```bash
python -m pip install -e '.[train]'
ygo-sky install-native
python -m pip install --no-deps -e native/ygoenv
```

CUDA 依赖使用 `python -m pip install -e '.[cuda]'`。这组版本固定了历史 JAX/CUDA ABI。
CPU 干净安装已验证；GPU 在兼容的现有实验环境执行成功，全新 CUDA 安装因下载速度未完成验收。
完整依赖快照与 `pip check` 结果见验收资源。首次 JAX 编译会明显慢于后续推理。

## 从源码构建引擎

联网构建需要 C++17 编译器、Python 开发头、OpenSSL 开发包与 xmake。

```bash
export PYTHON="$PWD/.venv/bin/python"
bash native/build.sh
```

`native/xmake.lua` 和 `native/repo/` 固定引擎提交与依赖版本。
已验收的编译使用 xmake 已缓存依赖，通过下面的构建器重建：

```bash
python native/build_cached.py --packages ~/.xmake/packages
python native/build_cached.py --packages ~/.xmake/packages --source native/bridge/ygoenv
```

输出二进制与 `build.json` 位于 `native/build-cache/` 和 `native/bridge-build-cache/`。
缓存构建器默认保存候选产物，行为回归通过后才应切换训练 runtime。
`install-native` 始终安装 manifest 中的参考训练二进制；TCP 桥使用独立包目录进行控制测试。
完整联网依赖下载构建与缓存构建是两个路径，本次只验收了缓存构建路径。

## HTTP 部署

```bash
ygo-sky serve --model base-463m --device cpu --host 127.0.0.1 --port 8765
# GPU: --device gpu
```

对外监听需设置环境变量 `YGO_API_TOKEN`，调用者发送 `Authorization: Bearer TOKEN`。
健康检查返回模型 hash 和累计步数。推理与 reset 请求要求显式 `session`，对局结束应调用 reset。
服务为单进程顺序处理，最多保留 1024 个会话；可作为小规模部署入口。

`deploy/Dockerfile` 提供 CPU 服务模板，资源通过 `/opt/sky/resources` 挂载，令牌通过环境变量注入。
`deploy/*.service` 提供 systemd 模板，需要创建服务用户、配置 `/etc/sky-policy.env` 并调整实际安装路径。
Docker 镜像构建和 systemd 守护运行尚未验收；HTTP 直接运行已完成真实模型请求验证。
