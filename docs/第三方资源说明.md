# 第三方资源与发布方式

| 内容 | 当前处理 | 待补充的来源或许可 |
| --- | --- | --- |
| ygo-agent / ygoenv Python 与 C++ 修改版 | 独立保存源码及上游 LICENSE | 保留 MIT 与 Apache 来源说明 |
| YGOPro core、xmake 依赖 | 训练构建固定 f96929650ff8685b82fd48670126eae406366734，已收集 MIT 正文 | 补齐静态链接依赖许可；遗留 EDOPro 配方不属于已验收构建 |
| 网络协议与 tracker | 保存 vendored netduel/replay 及 sources.json | 核实本地 Mirrorforce 上游及许可 |
| Lua 卡片脚本 | 保存完整运行脚本及 GPLv2 LICENSE | 精确上游提交未恢复，核对修改来源与再分发要求 |
| cards.cdb / strings.conf | 保存与 checkpoint 对应的版本 | 核实卡片数据来源与再分发条件 |
| 语义表 NPZ | 保存 frozen 表和 hash | 公开生成过程、输入来源和再分发条件 |
| YDK 卡组与 split manifests | 保存专家池与目标卡组，Git 归档通用 largepool-v3 的 14,339 副卡组及划分清单 | 按历史 manifest 记录来源与划分；公开副本调整登记在 hash 清单 |
| checkpoint | 独立模型资源目录 | 确认上游权重来源与发布条件，按 hash 下载 |
| 原 native SO | Linux x86_64 / CPython 3.11 参考资源，缓存重建及采样回归通过 | 补齐静态链接依赖许可与来源 |

根目录 LICENSE 的 MIT 授权覆盖本项目新增的原创整合代码与文档。已有上游代码继续适用原许可，
模型、卡片数据、网络组件及其他派生资源的许可分别列出；根目录 LICENSE 不对这些内容重新授权。

大资源通过独立 Release/模型托管发布。源码仓库保留下载清单、版本、hash 和小型测试资源，
避免把历史日志、用户信息、私人录像、管理认证数据与全部旧模型放入公共仓库。

公共仓库使用经过脱敏的发行副本，内部服务器路径已映射为上游仓库/提交或资源名称。
原始快照和内部来源清单只保留在本地整理工作区。

特别感谢 MirrorForce 的作者海之中道，与他的交流让我受益颇丰。

许可来源详见 `third_party/SOURCES.json`。感谢 [ygo-agent](https://github.com/sbl1996/ygo-agent) 作者和贡献者提供模型、训练与环境实现。`third_party/ygo-agent/LICENSE` 同时保留 Hastur 的 MIT 声明和 Garena envpool 的 Apache 2.0 声明；另附 Apache 2.0 正文。wheel 使用同内容的 `YGO-AGENT-LICENSE.txt` 保留这些声明，避免与新增代码的 `LICENSE` 重名。网络组件和资源的未明确许可仍如实记录，不能把全部组成部分直接标为 MIT。

历史训练器、网络、ygoai 依赖与原生源码见 [legacy-lineage](../third_party/legacy-lineage/README.md)。两份早期原生二进制单独发布，下载身份见 [historical-resources.json](../configs/historical-resources.json)。训练材料的归档完整性、历史计数与证据性质见[训练沿革](历史训练沿革.md)。
