## 两个训练计数器

**259M、463M 和 464M 是闪刀专家阶段累计环境步。** 专家模型继承通用预训练权重，并在分叉时将专家计数器设为 0。通用分叉权重已经训练到 861,929,472 步。

早期通用 checkpoint 文件名的 `M` 表示 `global_step / 2^20` 向下取整。例如 `20260826_50M` 的精确步数是 **53,137,408**，`20260914_822M` 的精确步数是 **861,929,472**。专家文件名 `259000320_steps` 则直接写出环境步数。

| 阶段 | 精确环境步 | 证据 |
| --- | --- | --- |
| 2026-08-25 通用 R0 | 0 → 49,991,680 | 启动日志记录 `checkpoint=None`、`tb_offset=0`、`seed=0` |
| 通用 R1 / R2 | 49,991,680 → 51,040,256 → 53,137,408 | 各次启动日志与保存记录 |

随机初始化阶段使用 32 个环境 × 2 个 actor 线程 × 32 个 rollout 步，每批 2,048 环境步；学习率 0.0003、seed 0、gamma 1.0、GAE lambda 0.95。模型使用结构化编码器、128 通道、512 维 LSTM。训练按内容簇均匀采样，日志记录 2,976 个训练簇。

## 源码与原生环境

早期训练器的 SHA256 与 8 月续训 manifest 一致；迁移前 JAX 网络与迁移备份一致。corrected 工程的四个模型文件与公开模型实现逐字节一致，其 PPO 训练器与历史归档 `cleanba.corrected0920.py` 一致。

早期 v11 与 tribute-fix 原生源码、二进制分别保存，两个二进制都核对了完整哈希。corrected 训练使用 `sky-selfplay-own-deck-candidates-v2`，其参考二进制已在 v0.1.0 发布。阶段间原生环境的切换应与对应的启动和修复记录一起核对，见[随机初始化历史训练](随机初始化历史训练.md)。
