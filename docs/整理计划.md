# 整理计划与完成情况

目标是把训练、验证、推理、部署和指定服务器/端口对战整理为独立工程，并保留可核查的模型与资源身份。

| 阶段 | 交付 | 状态 |
| --- | --- | --- |
| 来源收集 | 训练/专项/评估/部署原始快照，逐文件 hash | 完成，留在工作区 |
| 可运行工程 | src 包、统一 CLI、相对路径配置、模型契约 | 完成 |
| 训练与验证 | 三种 trainer、历史对手池、换座位评估、数据审计 | 完成代码整理；短训练及评估验收见报告 |
| 推理与接入 | CPU/GPU 推理、会话隔离 HTTP、指定 host/port TCP | 完成代码整理；233 实测见报告 |
| 原生资源 | 训练引擎/桥源码、固定依赖、重建与输入回归 | 重建完成，采样回归结果见报告 |
| 发行整理 | 源码/资源分包、脱敏、hash、独立解包验收 | 见 release/manifest.json 和验收报告 |
| 公开发布 | GitHub 公共仓库与独立 Release 资源 | zwdmw/GGBOY-ygoagent，新增代码 MIT，上游许可与未明确项分别记录 |

原始训练、历史线上服务和冻结卡组保留。实验使用新服务器的独立项目目录，生成的 smoke checkpoint 不替换科学基线。

后续应补充网络组件及资源的授权来源；新增原创整合代码与文档已采用 MIT。
需要补充科学评测时，应另建按来源划分的独立测试集、增加样本量并记录对战规则。
